技巧速查

听力：视听一致；转折词（but/however/actually）后出答案；同义替换是正确答案；听力结束立刻收答题卡1，必须边听边涂。 阅读：先看题干圈关键词 → 定位原文 → 同义替换比对；排除"偷换概念 / 以偏概全 / 无中生有 / 绝对化"；顺序 仔细阅读 → 匹配 → 选词填空。 写作：3 段，120–180 词，开头结尾背熟，中间两个理由 + 一个例子。 翻译：拆句 → 找主谓宾 → 逐句翻 → 检查时态和单复数；不会的词用解释法绕过去。
